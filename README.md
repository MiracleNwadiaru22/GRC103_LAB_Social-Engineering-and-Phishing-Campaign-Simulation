## Project Overview

A controlled phishing simulation conducted using **GoPhish** and **Mailtrap** to assess susceptibility to social engineering attacks and evaluate security awareness and phishing-reporting controls.

## Objectives

- Conduct a controlled phishing simulation.
- Assess susceptibility to phishing attacks.
- Measure email open, click-through, data submission, and reporting rates.
- Identify human-related security risks.
- Recommend appropriate security controls.

## Tools Used

| Tool | Purpose |
|---|---|
| GoPhish | Phishing campaign execution and tracking |
| Mailtrap | Email testing and delivery |

## Campaign Results

| Metric | Result | Rate |
|---|---:|---:|
| Emails Sent | 1/1 | 100% |
| Emails Opened | 1/1 | 100% |
| Links Clicked | 1/1 | 100% |
| Data Submitted | 1/1 | 100% |
| Emails Reported | 0/1 | 0% |

## Key Findings

- The recipient opened and interacted with the simulated phishing email.
- The recipient clicked the phishing link.
- A harmless dummy training code was submitted; no real credentials were collected.
- No phishing email was reported.

**Overall Assessment:** High human-risk indicator in this test.

*Note: The simulation involved only one recipient; therefore, the findings cannot be generalized to the entire organization.*

## Recommendations

1. Strengthen Multi-Factor Authentication (MFA).
2. Implement continuous security awareness training.
3. Conduct quarterly authorized phishing simulations.
4. Review and update the Acceptable Use Policy (AUP).
5. Establish clear phishing-reporting procedures.

## Conclusion

The exercise demonstrated the use of GoPhish in evaluating phishing susceptibility and identifying weaknesses in security awareness and reporting controls. The findings highlight the importance of continuous employee training and effective technical security controls.


For academic and cybersecurity risk assessment purposes. Conducted as a controlled simulation using dummy training data.*
